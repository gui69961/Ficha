## 📖 Sobre

**FICHA** é um marketplace gamer feito do zero com **HTML, CSS e JavaScript puro**, sem frameworks.
A loja reúne consoles, placas de vídeo, periféricos, cadeiras, jogos e acessórios, com uma experiência de compra
parecida com a dos grandes e-commerces: busca de produtos, navegação por categorias, cartões de produto com
preço, desconto e parcelamento, e um carrinho de compras.

O projeto foi pensado para praticar **manipulação do DOM**, **lógica em JavaScript** e **construção de interfaces responsivas e bem organizadas**.

## ✨ Funcionalidades

- 🛒 **Carrinho de compras:** adicione produtos pelo botão "Adicionar ao carrinho", com o contador atualizado no cabeçalho
- 🔎 **Sistema de busca:** pesquise consoles, placas de vídeo, teclados e outros produtos pela barra de busca
- 🗂️ **Navegação por categorias:** Tudo, Consoles, Placas de vídeo, Periféricos, Cadeiras & setup, Jogos e Acessórios
- 🌙 **Visual escuro (dark mode)** com destaques em amarelo, no estilo gamer

## 🧰 Tecnologias

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura semântica da página |
| **CSS3** | Layout, grid, flexbox, cores e estilo dos cartões |
| **JavaScript (ES6+)** | Carrinho, busca, filtros e atualização dinâmica da página |

## ▶️ Como executar

Não precisa instalar nada, nem rodar servidor. Abra o projeto direto no navegador:

1. Clone o repositório:

```bash
git clone https://github.com/gui69961/ficha.git
cd ficha
```

2. Abra o arquivo `index.html` com um duplo clique, ou arraste-o para uma janela do navegador.

> 💡 **Dica:** no VS Code, instale a extensão **Live Server**, clique com o botão direito em `index.html`
> e escolha **Open with Live Server** para a página atualizar sozinha a cada alteração.

## 📁 Estrutura

```text
ficha/
├── index.html        # Página principal
├── css/              # Estilos
├── js/               # Lógica do carrinho e da busca
└── screenshots/      # Imagens usadas neste README
```

> Se os nomes das suas pastas forem diferentes, ajuste esta árvore para refletir o que está no repositório.
